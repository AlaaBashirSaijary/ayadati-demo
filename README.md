# Ayadati — demo build (not for sale)

A time-limited demo of the Ayadati clinic app, made only for marketers to show
to doctors. It is **not** the product: it cannot be activated, ends on a date
fixed at build time, hides backup and import, cannot update or replace the real
app (different package id), and carries a permanent "demo" ribbon with the
marketer's name. This repository holds no licence secret, no signing key and
no API key.

Build one: Actions -> "Build marketing demo APK" -> Run workflow.
